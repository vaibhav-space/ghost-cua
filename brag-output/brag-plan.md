# Brag Plan: GhostCUA

## What is this app?
GhostCUA is a zero-interruption background macOS desktop automation engine and MCP server that lets Claude Code, Cursor, and Codex operate Meta AI and Gemini with 0 mouse movement and 0 focus theft.

## The angle
Most "computer use agents" hijack your screen, jerk your mouse pointer, and freeze your laptop. GhostCUA bypasses WindowServer entirely using process-targeted Carbon AppleEvents and Darwin Accessibility IPC. You keep writing code in your IDE while Claude delegates to native desktop apps in the background.

## Hook (first 2-3 seconds)
Big bold typography on a pristine off-white background:
"Your AI agent is stealing your mouse."
A cross icon flashes over a hijacked screen diagram, cutting sharply to:
"If you can't use your computer, it's not automation."

## Key moments (the middle)
- **Beat 1 (3-7s)**: The Telemetry Proof. Four stark numbers drop in with audible hits: `0px` cursor drift · `0ms` focus theft · `0` Space swooshes · `~500` lines clean Python.
- **Beat 2 (7-13s)**: Real-World Workflow. Claude Code in the terminal calls `ghost-cua-meta-ai`. Meta AI Thinking mode activates in the background, extracts 13,000+ characters of live Instagram Reel trend analysis, and pipes it back without stealing focus.
- **Beat 3 (13-16s)**: Gemini Video Superpowers. Long-form continuous video audio-sync audit via direct `aevt/odoc` staging.

## Outro / punchline (16-18s)
"Keep coding while your agent works."
GhostCUA logo reveal.
"100% Free & Open Source · MIT License · github.com/vaibhav-space/ghost-cua"

## User flow worth showing
Claude Code CLI prompt → Staging via FastMCP → Native background extraction → Live markdown stream back to terminal while VS Code retains unbroken keyboard focus.
